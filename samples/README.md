# Sample files

Made-up volunteers for trying the import. Every address uses example.com.

- `volunteers.csv`: 20 rows. Bea Smith and Beatrice Smith share an email, so the import offers to merge them. Noor Rahman has no email or phone, so that row is set aside.
- `volunteers.xml`: 3 people in XML, one with two skills.

Text, Word and PDF imports need a model set up on the server (`MODEL_PROVIDER` and `MODEL_API_KEY`).

`meeting-notes.txt` is sample board meeting notes for trying "Notes into tasks" in [the next version spec](../docs/specs/next-version.md).
